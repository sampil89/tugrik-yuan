# Tugrik Yuan — сайт (этап 1: основа)

Vite + React. Шапка, hero с формой заявки, живой курс валют, футер и
клиентская админ-панель (курс валют вручную + заготовки для новостей,
объявлений и заявок).

## Запуск

Нужен установленный Node.js (18+). В этой песочнице нет доступа к сети,
поэтому `npm install` нужно выполнить на вашей машине:

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Как устроено

- `src/App.jsx` — все компоненты сайта в одном файле (Header, Hero,
  ApplicationForm, CurrencyBoard, Footer, AdminLoginModal, AdminPanel).
  По мере роста проекта это стоит разнести на отдельные файлы в `src/components/`.
- Курс валют тянется с публичного API `open.er-api.com` (база MNT),
  автообновление раз в 30 минут, резервные значения — в константе
  `FALLBACK_RATES` наверху файла.
- Хранение данных (курс вручную, заявки, новости, объявления, сессия
  администратора) сейчас идёт через `localStorage` — то есть **только в
  браузере конкретного посетителя**. Это временное решение для первого
  этапа. Как только будет готов бэкенд (см. ТЗ, раздел 7 — Vercel
  Functions), функции `storageGet` / `storageSet` в начале `App.jsx`
  нужно заменить на вызовы API — сигнатуры специально оставлены простыми
  под такую замену.

## Что нужно сделать до реального запуска

- **Пароль администратора** сейчас захардкожен в `App.jsx`
  (`ADMIN_PASSWORD`). Это годится только для локальной проверки —
  перед деплоем нужна серверная авторизация, пароль не должен лежать
  в клиентском коде.
- Отправка заявок пока просто сохраняется локально — нужно подключить
  serverless-функцию и Telegram-бота (токен — только в переменных
  окружения сервера, см. `.env` в `.gitignore`).
- Логотип, соцсети и контакты в шапке/футере — заглушки, замените на
  реальные ссылки и файл логотипа.
